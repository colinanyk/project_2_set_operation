# Project Scope

Our program covers the following:

## Set Operations

The program will cover the following Set Operations:

- Sets
- Multi Sets
- Fuzzy Sets

## Execution Criteria

Each execution will cover the following criteria:

- Universe/Ordinary Sets: Stores all possible elements and allows set operation classes to access them.
- Set: Uses a Boolean array to track which elements are included. 
- Multiset: Uses an integer array to count how many times each element appears.
- Fuzzyset: Uses floating-point membership degree between 0.0 - 1.0 for each element for inclusivity.
- Both classes will include methods to display their elements and results.
